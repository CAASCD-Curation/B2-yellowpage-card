# 黄页经典艺术档案 · 表格图文交互卡

> 一份围绕「黄页」主题的内容策展档案：1883 年的黄纸传说，到数字时代的消亡与再生。
> 200 条档案条目（4 大分类 × 各 50 条），以表格 + 图文卡片的形式交互呈现。

## 项目简介

本项目是一份「黄页」主题的经典艺术档案库，将印刷时代的商业名录作为文化符号进行系统性采集与策展。档案覆盖四类素材：

| 分类 | 副题 | 条目数 |
| --- | --- | --- |
| 经典艺术档案 | 标志性视觉资产：标志 / 字体 / 广告片 / 雕塑 / 封面 / 网页设计 | 50 |
| 文学意象 | 小说 / 影视 / 歌曲 / 广告文案 / 俗语 / 网络文本中的黄页意象 | 50 |
| 社会素材 | 商业史 / 制度 / 民俗 / 环保 / 数字替代的社会断面 | 50 |
| 形式灵感 | 信息架构 / 网格 / 字体 / 配色 / 印刷约束 / 数据化谱系 | 50 |

每条档案包含：编号（ID）、名称、类型、摘要、来源、原始链接、年代、标签、采集渠道、备注、核实状态与配图。

## 功能特性

- 📇 **档案卡片**：每条目一张图文卡片，含配图画廊与详情弹窗
- 🗂️ **四大分类标签页**：经典艺术档案 / 文学意象 / 社会素材 / 形式灵感
- 🏷️ **标签筛选**：按媒介、主题、地域、年代等标签维度过滤条目
- 🔍 **检索匹配**：名称、摘要、来源全文检索
- 📊 **统计面板**：按类型、年代、状态汇总档案概况
- 🖼️ **图片画廊**：支持多图切换浏览

## 快速开始

### 方式一：直接打开（推荐）

`app/index.html` 为零依赖单文件应用，双击或拖入浏览器即可使用。

### 方式二：Vue 版本

```bash
cd yellow-pages-vue
npm install
npm run dev      # 开发预览
npm run build    # 构建到 dist/
```

## 数据格式

`app/data.json` 顶层按分类组织，每个分类含 `subtitle` 与 `entries` 数组：

```json
{
  "经典艺术档案": {
    "subtitle": "标志性视觉资产：…",
    "entries": [
      {
        "id": "ART-01",          // 条目编号
        "name": "…",              // 名称
        "type": "图文",           // 类型：文 / 图 / 图文 / 影像 等
        "summary": "…",           // 摘要
        "source": "…",            // 来源
        "link": "https://…",      // 原始链接
        "year": "1883",           // 年代
        "tags": "＃媒介:印刷 …",   // 标签串
        "channel": "…",           // 采集渠道
        "note": "…",              // 备注
        "status": "已核实",        // 核实状态
        "images": ["image42.jpeg"] // 配图文件名
      }
    ]
  }
}
```

新增条目：在 `app/data.json` 对应分类的 `entries` 中追加对象，并将配图放入 `app/images/` 后在 `images` 字段引用文件名即可。
